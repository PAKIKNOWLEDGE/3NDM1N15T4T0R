## 站点技术特征（可直接观察）

- Next.js（App Router）静态站，资源走自建 CDN `web.hycdn.cn`：
  - 主视觉/分享图：`/endfield/official-v4/_next/static/media/*`
  - 公告与活动图：`/upload/image/<yyyymmdd>/<hash>.{jpg,png}`
- 图片按日期分目录归档，命名是内容哈希 —— 与我们「素材按时段归档、文件名非语义」的做法一致。
- 页面结构以横幅（1600×900 / 1920×1080）为主，1:1 方图仅用于分享卡。

## 取色采样（量化 16 级，误差 ±15/通道）

方法：Pillow 抽样 + 直方图量化（`assets/official-site/` 下 5 张）。**非取色器精确值**，
但足以确定色调与明度关系。

| 素材 | 基底 | 主色占比 | 信号色 | 信号色占比 |
| --- | --- | --- | --- | --- |
| `notice-0ffe54e3` 水墨竖排 | 近白 `#f0f0f0` + 墨黑 `#101010` | 白 37% / 黑 10% | 赭红 `#b03030` 系 | < 1% |
| `notice-582e9e65` 暗底武器 | 墨青黑 `#001010` / `#000010` | 27% | 信号黄 `#f0f020` / `#908010` | ≈ 1% |
| `notice-9e816139` 角色获得 | 淡紫白 `#e0a0f0` + 近白 | — | 紫罗兰 `#9030d0` / `#b050f0` | ≈ 4% |
| `notice-dde7c30f` 浅底版本 | 近白 `#f0f0f0` + 浅绿 `#e0f0c0` | 白 17% | 嫩绿 `#80b050` | < 1% |
| `share-keyart` 分享卡 | 黄绿 `#e0e060` 系 | — | 同色系 + 暗酒红块 | ≈ 50%（主色即信号色） |

**核心规律**：基底只有两档（近白 `#f0f0f0` / 近黑 `#001010`），信号色**固定一个色相、按基底切换明暗两档**
（暗底用满明度 `#f0f020`，浅底换低饱和绿/赭红）；信号色面积 **≤ 5%（分享卡除外，那是海报体例）**。
这与我们 `tokens.json` 的 `accentSinkRule` 完全同构。

## 版式（视觉走查结论）

- **中文标题超粗无衬线、直接压图、不加实心底板**；唯一近似底板的是描边式标题（笔画间隙透底色）。
- **中英双层固定层级**：中文主标题 : 英文小注 ≈ **3:1 ~ 5:1**，英文全大写 + 字距 `0.15–0.35em`，
  永远在中文**下方或右侧**，绝不抢占第一眼。
- **允许出血裁切**：人物头部/肩部可被画面边缘切掉；**标题永不裁切**。
- **技术留白**：留白 40–55%，且是**为细线与小字预留**的整块空间，不是均匀分布。
- 分区稳定为「**图左字右 / 图上周下**」，logo 控制在画面高度 10% 以内、贴角放置。

## 图形语言（多张共有 → 可写进规范）

1. **1px 细线 + 刻度段**（暗底黄线、浅底灰线）
2. **端点小十字 / 定位加号**
3. **成组三点箭头 `▸▸▸`**
4. **L 形角括号**围住标题
5. **超小号全大写拉丁注记**沿细线排布（小到接近纹理）
6. **小方块/点阵网格**与**半调网点**质感

（单张独有、不建议体系化的：彩色色条芯片、手写体覆盖、故障像素块。）

## 可迁移到 Web 设计语言的 5 条做法

1. **基底取极值 + 强调色只给一处**：底要么 `#f5f6f3` 级近白、要么 `#202329` 级近黑；
   强调色固定 1 个，浅底用低饱和档、深底才用满明度档；占比 5–10% 以内，永不铺满。
2. **超粗标题压图、不加底板**：`font-weight: 900`、`letter-spacing: .02em`、字号 ≥ 同级英文 3 倍；
   第二层用「1px 分隔线 + `letter-spacing:.2em; text-transform:uppercase` 的英文小注」，而不是色板。
3. **工业细线系统组件化**：1px 线 + 刻度段 + 端点十字 + `▸▸▸` + L 形角括号，统一 4–8px 节奏；
   只出现在标题上下沿、页脚、卡片四角，**绝不进入正文阅读区**。
4. **技术留白而非均匀留白**：标题区周边整块留 40% 以上给细线与小字；允许图片出血、禁止标题裁切。
5. **图像叠层模板**：主角清晰 + 背后 15–30% 透明度的剪影/群像 + 朝文字侧线性渐隐，
   保证文字永远落在无干扰区；页脚低位小号 `© HYPERGRYPH` 与版本/编号注记，透明度 50–60%。

## 与本仓库设计语言的关系

**重合（互相印证）**：中性底 + 单信号色小面积 + 超粗标题压图 + 双语层级 + 细线刻度装饰 + 底部收边。
**本仓库未吸收（可作为扩展）**：出血裁切构图、多重曝光/幽灵群像、半调网点与水墨飞白、竖排标题。
